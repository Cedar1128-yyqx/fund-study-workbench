# 资本人生 · 第一笔投资

这是《基金从业学习工作台》的科目三试玩。下载本分支的 `index.html`，用浏览器打开，点右上角「资本人生」。无需安装或登录。如需在多次打开时稳定使用同一个浏览器存储空间，可在文件所在目录运行 `python3 -m http.server 8765`，访问 `http://localhost:8765`。学习记录随浏览器和网址保存，换网址时可用页面原有的学习备份导入。

## 界面与玩法

| 位置 | 玩家能做什么 |
| --- | --- |
| 投资机构 | 查看模拟基金可投余额、已投金额、LP 信任和待审项目 |
| 办公室 | 填姓名、选履历，从投资助理起步。查看导师任务和错题，交割后查看结案复盘 |
| 项目会场 | 审核机器人公司的增资备忘录，处理关联方冲突，完成模拟交割 |
| 工作台路线 | 查看待复习的剧情错题，打开变式题或原课程知识点。可读旧版错题并复制、恢复旧版 JSON 备份 |

主线是入职 → 核算增资 → 处理冲突 → 模拟交割 → 复盘。基金初始有 8,000 万元可投资金，正确审核并完成案例合同程序后，可模拟投入 5,000 万元。估值错误会退回备忘录，隐瞒关联关系等选择会让交易暂停，并留下对应的信任或合规扣分。错题可立即订正，也可日后复习。变式题连续答对三次后归档，每次之间安排 1 天、3 天的复习间隔。

## 数据与教材

- `capital-life.v1` 存角色、场景、两项任务的选择与错误次数、交割状态、错题及复习日。点「手动保存」才写入游戏存档。日期采用上海时区。
- 剧情估值映射到原课 `2:4:3`（交接版章节 `s2c4`），基金治理映射到 `2:7:2`（`s2c7`）。完成原课自己的小测与掌握度记录后，才更新原课成绩。现版 `fund-study-course-v2` 与原 JSON 备份兼容。
- 交接版 `fundq.v1` 保留原章节 ID 和 JSON 字段。路线页可查看该存储中的错题并复制、粘贴旧版备份。导入到当前浏览器与网址，保留原来的章节进度、知识节、错题和其他字段。
- 依据中国证券投资基金业协会组编《股权投资基金》（2025），第五章第四节「交易文件」印刷页 158（完整 PDF 第 167 页）与第八章第二节「股权投资基金治理主要原则」印刷页 266–268（完整 PDF 第 271–273 页）。机器人公司、金额、合同流程和交割结果为自编案例。教材文件留在本地。

## 验收清单

- 脚本能解析，现有四个工作台入口与原课程小测可用。
- 建角后能切换三个场景。机器人案例算出投后 1.5 亿元、持股约 33.33%。
- 两题分别答错时出现各自的剧情后果、教材页码、错题和原课入口。变式题订正后更新复习日。
- 合规选项通过并确认模拟交割后，余额为 3,000 万元。重复访问不会再次扣款。
- 手动保存后刷新能继续，旧版 JSON 和现版备份均可导入并导出。
- 桌面和窄屏都能完成关键流程，页面无横向溢出。
