# 基金从业学习工作台

面向零基础学习者的基金从业学习页面，包含三科课程、章节与知识点、生活场景、选择题、思维导图、学习计划、进度记录和术语工具箱。

## 使用

- 打开 GitHub Pages 网页即可开始学习，不需要注册或登录。
- 学习进度会自动保存在当前浏览器。同一浏览器下次打开会接着学习。
- 页面提供学习记录导出与导入功能，可用于备份或手动迁移到其他设备。

## 进度与隐私

- 当前版本只在本机浏览器保存学习记录，不会连接 Supabase，也不会跨设备自动同步。
- 清除浏览器网站数据会删除本机进度；需要长期备份时，请使用页面中的导出功能。
- 仓库保留的 `supabase-setup.sql` 是未来云同步的参考脚本；当前工作台不会运行它。
- 发布包不包含教材 PDF 或本机学习记录。教材原件请在本机另行保存。
